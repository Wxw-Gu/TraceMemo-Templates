# 投稿前自检

## 来源和设计

- [ ] 已阅读用户提供的原项目、源码/截图和资源许可。
- [ ] 模板保留了原日报的主要层级、比例、留白、字体气质和颜色关系；已记录无法保留的部分。
- [ ] 没有把截图猜测或原项目私有字段当成 TraceMemo 新字段。

## 仓库规则

- [ ] 已重新读取当前 `CONTRIBUTING.md`、validator、preview/build 脚本、fixture、manifest 示例和相关模板。
- [ ] `templates/<id>/<version>/` 包含正确的 `manifest.json`、入口 HTML 和声明的包内资源。
- [ ] ID、semver、协议、接口、entry、capture、license 与当前 validator/示例一致。
- [ ] 使用的每个占位符都来自当前仓库；text、html、class 没有混用，也没有放进样式、URL、事件属性或未知标签。

## 安全和兼容

- [ ] 没有 JavaScript、事件属性、iframe、表单、外部 API、外链图片/字体/样式、`@import` 或目录外文件读取。
- [ ] 没有危险 URL、动态执行、localStorage、登录或自定义业务逻辑。
- [ ] 未引入 unsupported 数据、业务字段、AI prompt 或对 TraceMemo 主程序的修改。
- [ ] 图片仅来自包内允许格式和大小范围，并有可分发的许可说明。

## 数据和版式

- [ ] 完整 fixture 与空/稀疏模块都不会留下空标题、空边框或错误间距。
- [ ] 长中文、长英文、长数字和 HTML 特殊字符可读且不会横向溢出。
- [ ] 消息区正确处理小尺寸头像存在/缺失、超长昵称、时间、正文/气泡和备注；多人、多条消息不会重叠。
- [ ] 在目标手机宽度实际检查过：头像与图片消息没有混淆，消息可换行且没有横向溢出。
- [ ] 重要消息、引语、话题、问答、行动项和未解决项与实际可用占位符一一对应。
- [ ] preview 实际打开检查过，宽度符合 capture，页面没有裁切、重叠、不可读文本或异常空白。

## 验证和交付

- [ ] 已运行覆盖候选模板的 validator；固定枚举既有模板的 validator 仅作为基线，其覆盖范围已如实说明。
- [ ] 已运行覆盖候选模板的 preview 流程，并检查了 PNG/HTML 实际效果；不是仅确认 PNG 存在。
- [ ] 已运行覆盖候选模板的 build/package 流程，ZIP 只含允许文件；需要时已运行生产安装/导出探针。
- [ ] 所有验证均使用虚构数据，没有真实聊天记录、头像、密钥或隐私。
- [ ] 已准备源码、preview、命令结果、兼容性说明、PR title 和 PR description。
- [ ] 第一版未修改正式 catalog，未在用户确认满意且明确授权投稿前创建公开 PR。
